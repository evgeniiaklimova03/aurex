# AUREX — Прогресс проекта

## Текущий этап: Основная разработка завершена, проведена финальная проверка

Все этапы разработки готовы: страницы, фильтры каталога, избранное, сравнение, контакты, личный кабинет (демо).

## Принятые решения:
- Тип: автомобильный маркетплейс (учебный, портфолио).
- Стек: React + Vite + JavaScript + CSS + React Router + Lucide + localStorage. Без бэкенда.
- Данные: 12 авто в src/data/cars.json.
- Фичи: каталог с фильтрами и поиском, избранное, сравнение (макс. 3) с подсветкой отличий, коллекции на главной.
- Личный кабинет: /account с табами (демо, данные профиля вымышленные).
- FAQ и форма заявки: на /contacts (заявки сохраняются в localStorage).
- Дизайн: тёмная тема, акцент #C6FF6B, шрифт Manrope.

## Маршруты и страницы (src/pages)
| Маршрут | Страница |
|---|---|
| / | Home.jsx — главная |
| /catalog | Catalog.jsx — каталог с фильтрами |
| /catalog/:id | CarDetail.jsx — карточка авто |
| /favorites | Favorites.jsx — избранное |
| /compare | Compare.jsx — сравнение |
| /about | About.jsx — о проекте |
| /contacts | Contacts.jsx — контакты, форма, FAQ |
| /account | Account.jsx — личный кабинет (демо) |

## Компоненты (src/components)
- layout/: Layout, Header, Footer
- ui/: Container
- home/: Hero, FeaturedCars
- cars/: CarCard

## Остальной код
- context/AppContext.jsx — избранное и сравнение
- hooks/useLocalStorage.js — безопасная работа с localStorage
- utils/carLabels.js — подписи и форматирование цен/пробега
- utils/requests.js — хранение заявок в localStorage
- data/cars.json — данные автомобилей

## Финальная проверка
- Сборка `npm run build` проходит без ошибок.
- Линтер: 2 мелких предупреждения (не влияют на работу).
- Ревью: критических ошибок нет. Исправлено: кнопка-сердечко на карточке авто теперь реально добавляет в избранное.

## Известные недочёты (не критично)
- Картинки авто загружаются с внешних URL (Wikimedia, Unsplash), локальной папки public/images/ нет.
- В Account вместо встроенных сообщений используются alert().
- Цифры на About и текст в Hero («Тысячи объявлений») демонстрационные.
- Нет skip-ссылки, title страницы не меняется при навигации.
- Адаптивность на 375/768/1024/1440 нужно проверить вручную в браузере.
