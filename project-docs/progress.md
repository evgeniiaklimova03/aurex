# AUREX — Прогресс проекта

## Текущий этап: Разработка завершена, сайт опубликован

Все этапы разработки готовы: страницы, фильтры каталога, избранное, сравнение, контакты, личный кабинет (демо).

## Принятые решения:
- Тип: автомобильный маркетплейс (учебный, портфолио).
- Стек: React + Vite + JavaScript + CSS + React Router + Lucide + localStorage. Без бэкенда.
- Данные: 12 авто в src/data/cars.json.
- Фичи: каталог с фильтрами и поиском, избранное, сравнение (макс. 3) с подсветкой отличий, коллекции на главной.
- Личный кабинет: /account с табами (демо, данные профиля вымышленные).
- FAQ и форма заявки: на /contacts (заявки сохраняются в localStorage).
- Дизайн: тёмная тема, акцент #C6FF6B, шрифт Manrope.

## Резюме проекта
AUREX — концептуальный автомобильный маркетплейс (учебный проект для портфолио, без бэкенда).

**Реализовано:**
- главная страница с коллекциями авто;
- каталог с фильтрами и поиском;
- карточка автомобиля с галереей и контактами продавца;
- избранное и сравнение до 3 авто с подсветкой различий;
- страницы «О платформе» и «Контакты» (форма заявки, FAQ);
- личный кабинет (демо);
- адаптивная вёрстка (mobile-first), тёмная тема, базовая доступность (aria, фокус, skip-link).

**Технологии:** React, Vite, JavaScript, CSS, React Router, Lucide Icons, localStorage (избранное, сравнение, заявки), GitHub Actions + GitHub Pages.
