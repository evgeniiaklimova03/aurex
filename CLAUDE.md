# AUREX — Контекст для Claude Code

## Что это за проект
AUREX — концептуальный автомобильный маркетплейс для портфолио. Учебный проект, но по структуре и качеству должен соответствовать реальному продукту.

## Стек
React + Vite + JavaScript + CSS + React Router + Lucide Icons + localStorage. Проект инициализирован, react-router-dom и lucide-react установлены. Без бэкенда. Без дополнительных библиотек без согласования.

## Ключевые правила
1. Не ломать существующую функциональность.
2. Не удалять файлы и компоненты без явного разрешения.
3. Все кнопки и ссылки должны работать (если функциональность демо — честно обозначать).
4. Адаптивность: mobile-first, проверка на 375 / 768 / 1024 / 1440.
5. Код простой и читаемый, без чрезмерной сложности.
6. Не устанавливать библиотеки без обоснования и согласования.

## Где что лежит
- project-docs/ — документация (ТЗ, схема данных, прогресс).
- src/ — код приложения. Структура создана: components/, pages/, data/, hooks/, utils/, styles/. Сейчас в App.jsx только заготовка.
- public/ — статические файлы (создана). public/images/ для изображений авто — ещё не создана.
